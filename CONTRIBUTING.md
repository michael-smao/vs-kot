# Contributing to vs-kot

vs-kot is a fork of [Code - OSS](https://github.com/microsoft/vscode) that one team builds for its own daily work. It is young, and it stays close to upstream on purpose.

## Issues

Problems with what vs-kot adds or changes belong in the [issues](../../issues) of this repository: the change review, tab completion, the team settings, the reduced interface, updates, and the build and release scripts. The [README](README.md) describes each of them.

A problem that also shows in Visual Studio Code is upstream's. Please report it at [microsoft/vscode](https://github.com/microsoft/vscode/issues), not here.

Security problems do not go into the issue list, see [SECURITY.md](SECURITY.md).

## Changes

Please open an issue before you put work into a pull request, so that we can talk about it first.

The README says how to build from source and how the fork is organised. Our code lives in folders of its own, and edits to upstream files are kept small and carry a `vs-kot:` comment. The coding guidelines are upstream's.
